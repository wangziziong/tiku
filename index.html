🤖 AI 接口配置（不配置也能用全部手动功能）

推荐「智谱开放平台」：open.bigmodel.cn 注册后在「API密钥」页创建 Key， 免费模型 glm-4.5-flash（文字）、glm-4v-flash（看图）即可驱动本工具全部 AI 功能。其他 OpenAI 兼容服务（DeepSeek、Kimi、本地 Ollama 等）换地址和模型名同样可用。
🔒 你的 AI Key 只保存在你自己的云账号和本机浏览器里，不会出现在网站代码中，其他注册用户的账号里也看不到，互不影响。
怎么单独换视觉模型（对话不受影响）：在「视觉专用 API 地址 / Key」里填另一家的接口就行。想让抠图用 qwen-vl-max（图形定位最准）：
① 注册阿里云「百炼」bailian.console.aliyun.com（需阿里云账号），在右上角「API-KEY」页创建一个 sk- 开头的 Key（新用户有免费额度）；
② 视觉专用 API 地址填 https://dashscope.aliyuncs.com/compatible-mode/v1，视觉专用 Key 填 sk-…，视觉模型改成 qwen-vl-max；
③ 点「测试视觉」验证能读图即可。不想注册新账号的话，也可以把视觉模型改成智谱自家的 glm-4v-plus（主 Key 直接用，付费但很便宜）。
AI 自动抠图依赖视觉模型的图形定位能力；若定位不准，可在题目上用「✂裁图」手动框选。

💾 数据管理（所有数据只保存在这台电脑的浏览器里）

建议每周导出一次备份。清除浏览器缓存或换电脑会导致数据丢失，用「导出备份 / 导入备份」迁移。

👤 云账号（邮箱注册登录 · 换设备自动同步）

已登录：　改动会自动同步云端；换设备打开本工具登录同一账号，题库自动合并。
数据存在 Supabase 云端你自己的账号里（按账号严格隔离，别人看不到你的题库）。你的 AI Key 也只绑定在你自己的账号和设备上，朋友的账号互不相通。容量：免费版 500MB（约能存几万道题，够用很多年）；项目若连续 7 天没人使用会自动休眠，登录一次网站即可唤醒，数据不会丢。退出登录会清空本机缓存，防止共用电脑时资料留在机器上。

☁ 多设备同步（GitHub Gist 备用方案）

用法：本电脑点「上传到云端」→ 在另一台电脑打开本工具 → 设置 → 填同一个 Token 和「云端备份 ID」→ 点「从云端合并」（两边合在一起）或「用云端覆盖本地」（以云端为准）。
Token 获取：github.com → 右上角头像 → Settings → 页面最底部 Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic) → 勾选 gist → 生成后复制。

📖 使用说明

1.「我的题库」点「📎 上传文件」丢进照片、PDF 或 Word（.docx）即可——切题、打标签、补答案、抠图全部自动完成；也可以手动录入或粘贴文本。
2. 勾「＋试题篮」攒题，一键生成试卷，可打印（学生版/教师版）、导出 Word 或 PPT 课件。
3. 每道题可用「AI变式」生成同考点变式题，用「AI讲题」生成讲题稿；点「错题」收录进错题本，可按知识点统计、生成重练卷。
4.「AI出题」按年级、学科、知识点直接让 AI 命题入库；「设置」里可多设备云同步。
